### 2. PrefabGeneratorTool.cs
**Location:** `Assets/Scripts/Editor/PrefabGeneratorTool.cs`  
**Access:** Unity Menu → `EarthUnderFreelancer → Tools → Prefab Generator`

**Features:**
- Generates aircraft prefabs with placeholder meshes
- Generates weapon prefabs
- Generates projectile prefabs
- Generates station prefabs (with docking arms)
- Automatic directory creation
- Sample generation buttons
- Configurable output paths

**Technical Details:**
- Uses `sharedMaterial` for performance (no memory leaks)
- Creates proper hierarchies (fuselage, wings, tail for aircraft)
- Adds physics components (Rigidbody, Collider)
- Team-based coloring (WW2 vs Modern)
- One-click batch generation

**Generated Prefabs:**
- P-51D Mustang, Bf 109 G-6, Spitfire Mk IX
- F-16 Fighting Falcon, MiG-29 Fulcrum
- MG, Cannon, Rocket, Missile weapons
- Bullet, Shell, Rocket, Missile projectiles
- Space Station with docking arms

## How to Use (Quick Start)

### Step 1: Open Unity
```
Unity Hub → Add → Select EarthUnderFreelancer folder
Open with Unity 2022.3 LTS
```

### Step 2: Generate Scene
```
Unity Menu → EarthUnderFreelancer → Tools → Scene Template Generator
Click "Create GameScene"
```

### Step 3: Generate Prefabs (Optional)
```
Unity Menu → EarthUnderFreelancer → Tools → Prefab Generator
Click "Generate All Selected"
```

### Step 4: Play!
```
Open GameScene.unity in Project window
Press Play ▶️
Press F1 for developer tools
Use WASD + Mouse to control camera
```
