## Development Workflow

### Using Claude Code

1. Navigate to your project directory
2. Run `claude` to start the coding assistant
3. Use natural language to:
   - Generate boilerplate code
   - Refactor existing code
   - Write documentation
   - Manage git workflows

### Example Commands

**Note:** The commands below are illustrative examples. Run `claude` first to start the interactive session, then use natural language prompts like these:

```bash
# Initialize a new project
claude "Create a new React app with TypeScript"

# Add features
claude "Add user authentication with JWT"

# Write tests
claude "Generate unit tests for the auth module"

# Documentation
claude "Generate API documentation"
```
