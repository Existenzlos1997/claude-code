============================================================
SYSTEM REQUIREMENTS
============================================================

MINIMUM REQUIREMENTS:
- OS: Windows 10 (64-bit)
- Processor: Intel Core i5-4460 / AMD FX-6300
- Memory: 8 GB RAM
- Graphics: NVIDIA GTX 1050 / AMD RX 560 (2GB VRAM)
- DirectX: Version 11
- Storage: 20 GB available space
- Network: Broadband Internet connection

RECOMMENDED REQUIREMENTS:
- OS: Windows 11 (64-bit)
- Processor: Intel Core i7-8700 / AMD Ryzen 5 3600
- Memory: 16 GB RAM
- Graphics: NVIDIA RTX 2060 / AMD RX 5700 (6GB VRAM)
- DirectX: Version 12
- Storage: 50 GB SSD
- Network: High-speed Internet connection

============================================================
INSTALLATION STEPS
============================================================

1. PREPARATION
   - Ensure your system meets the minimum requirements
   - Close all other applications
   - Disable antivirus temporarily (some may flag game files)
   - Ensure you have administrator rights

2. RUN THE INSTALLER
   - Double-click EarthUnderFreelancer_Setup.exe
   - Click "Yes" if prompted by User Account Control

3. CHOOSE LANGUAGE
   - Select your preferred language
   - Click "OK" to continue

4. WELCOME SCREEN
   - Read the welcome message
   - Click "Next" to continue

5. LICENSE AGREEMENT
   - Read the End User License Agreement
   - Select "I accept the agreement"
   - Click "Next" to continue

6. SELECT DESTINATION
   - Choose where to install the game
   - Default: C:\Program Files\EarthUnderFreelancer
   - Ensure you have at least 20 GB free space
   - Click "Next" to continue

7. ADDITIONAL OPTIONS
   - Choose whether to create desktop shortcut
   - Choose file associations
   - Click "Next" to continue

8. READY TO INSTALL
   - Review your choices
   - Click "Install" to begin installation

9. WAIT FOR INSTALLATION
   - The installer will copy all necessary files
   - Additional components (DirectX, Visual C++) may be installed

10. INSTALLATION COMPLETE
    - Check "Launch EarthUnderFreelancer" to start playing
    - Click "Finish" to exit the installer

============================================================
FIRST LAUNCH
============================================================

1. The game launcher will start
2. Create an account or log in
3. The launcher will check for updates
4. Click "PLAY" to start the game

============================================================
TROUBLESHOOTING
============================================================

GAME WON'T START:
- Update your graphics drivers
- Run as administrator
- Verify Visual C++ Redistributable is installed
- Check Windows Firewall settings

POOR PERFORMANCE:
- Lower graphics settings in the launcher
- Close background applications
- Update graphics drivers
- Ensure your PC meets requirements

CONNECTION ISSUES:
- Check your internet connection
- Verify firewall allows the game
- Try a different server region
- Check server status on our website

CRASHES:
- Update graphics drivers
- Verify game files through launcher
- Disable overlays (Discord, Steam, etc.)
- Check for Windows updates
