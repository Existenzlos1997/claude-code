# Earth Under Freelancer

This directory contains an example project demonstrating Claude Code's capabilities for freelancer workflows.

## Overview

EarthUnderFreelancer is a sample project that showcases how Claude Code can assist freelancers with:
- Project setup and scaffolding
- Code generation and refactoring
- Documentation creation
- Git workflow management

## Structure

- `README.md` - This file, providing project documentation
- `project-template.md` - A reusable template for freelancer projects
- `example-workflow.md` - Step-by-step guide for using Claude Code in freelance projects

## Usage

Navigate to this directory and use Claude Code to explore the examples and workflows demonstrated here.

```bash
cd EarthUnderFreelancer
claude
```

## Purpose

This serves as a reference implementation for freelancers using Claude Code to streamline their development workflow.
