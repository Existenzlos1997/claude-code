## 🚀 Schnellstart

### Mit phyphox App (empfohlen):

1. **Installieren Sie phyphox** (kostenlos):
   - iOS: App Store → "phyphox"
   - Android: Play Store → "phyphox"

2. **Daten aufzeichnen:**
   - Öffnen Sie phyphox
   - Wählen Sie "Acceleration" oder "Gyroscope"
   - Drücken Sie ▶ (Start)
   - Bewegen Sie das Smartphone
   - Drücken Sie ⏸ (Stop)

3. **Daten exportieren:**
   - Tippen Sie ⋮ (Menü)
   - Wählen Sie "Export Data"
   - Wählen Sie "CSV"
   - Speichern/Teilen Sie die Datei

4. **ICQ berechnen:**
   - Öffnen Sie: `smartphone_app_phyphox.html` (Link oben)
   - Laden Sie Ihre CSV-Datei hoch
   - Sehen Sie ICQ-Ergebnisse sofort!

### Oder mit Beispieldaten testen:

1. Laden Sie die App: `smartphone_app_phyphox.html`
2. Laden Sie Beispieldaten: `examples/phyphox_sample_data.csv`
3. Sofort Ergebnisse sehen!

## 💡 Tipp: Link speichern

**Auf dem Smartphone:**
- Öffnen Sie einen der Links oben
- Fügen Sie die Seite zu Ihren **Lesezeichen** hinzu
- Oder speichern Sie die Seite lokal (siehe DOWNLOAD_LINKS.md)

**Auf dem Computer:**
- Klicken Sie mit rechts auf den Link
- "Link speichern unter..."
- Datei auf Smartphone übertragen
