## 📥 Wie nutzen?

### Smartphone-Apps herunterladen:
1. **Link kopieren** (z.B. smartphone_app_phyphox.html)
2. **Im Browser öffnen** (Chrome, Safari, Firefox)
3. **Seite speichern**: 
   - **iPhone:** Teilen → Als PDF/Files speichern
   - **Android:** Menü → Seite speichern
4. **Gespeicherte Datei öffnen** → App läuft offline!

### Dokumentation lesen:
1. **Link kopieren**
2. **Im Browser öffnen** → Markdown wird als Text angezeigt
3. **Optional:** Seite speichern oder kopieren
