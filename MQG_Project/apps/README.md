# MQG Praktische Anwendungen

## Übersicht

5 sofort einsatzbereite Anwendungen, die die MQG-Theorie (ICQ) im Alltag nutzen:

### 1. Schlaf-Qualität-Monitor 🛌
**Datei:** `schlaf_monitor.html`

Messen Sie Ihre Schlafqualität durch Bewegungsanalyse.
- Nachtaufzeichnung mit Smartphone-Sensor
- ICQ-basierte Qualitätsbewertung (0-100)
- Schlafphasen-Erkennung
- Verlaufsdiagramm
- Verbesserungs-Tipps

**Nutzung:** Smartphone neben Bett legen, Aufzeichnung starten, morgens stoppen.

### 2. Lauftechnik-Analyzer 🏃
**Datei:** `lauftechnik_analyzer.html`

Analysieren Sie Ihre Lauftechnik in Echtzeit.
- Schritt-Konsistenz-Messung
- Symmetrie-Check (links/rechts)
- Schrittfrequenz (SPM)
- Technik-Score (0-100)
- Training-Historie

**Nutzung:** Smartphone am Arm befestigen, laufen, Analyse erhalten.

### 3. Audio-Qualität-Checker 🎤
**Datei:** `audio_quality.html`

Prüfen Sie die Qualität von Audio-Aufnahmen.
- Echtzeit-Mikrofon-Analyse
- Störgeräusch-Detektion
- Klangqualität-Bewertung
- Frequenz-Spektrum
- Aufnahme-Empfehlungen

**Nutzung:** Mikrofon erlauben, sprechen/singen, Qualität prüfen.

### 4. Herz-Kohärenz-Trainer ❤️
**Datei:** `herz_kohaerenz.html`

Trainieren Sie Ihre Herzratenvariabilität.
- HRV-Analyse (CSV-Upload von Smartwatch)
- Kohärenz-Score via ICQ
- Stress-Level-Bewertung
- Geführte Atem-Übungen
- Fortschritts-Tracking

**Nutzung:** CSV von Fitbit/Apple Watch hochladen, Analyse erhalten.

### 5. Maschinen-Vibrations-Monitor ⚙️
**Datei:** `maschinen_monitor.html`

Überwachen Sie Haushaltsgeräte auf Probleme.
- Vibrations-Muster-Analyse
- Anomalie-Erkennung
- Baseline-Kalibrierung
- Wartungs-Vorhersage
- Multi-Geräte-Verwaltung

**Nutzung:** Smartphone auf Gerät legen, Baseline erstellen, überwachen.

## Schnellstart

1. **Download:** HTML-Datei speichern
2. **Öffnen:** Im Browser öffnen (Chrome, Safari, Firefox)
3. **Erlauben:** Sensor-Zugriff zulassen
4. **Nutzen:** Sofort loslegen!

## Gemeinsame Features

Alle Apps bieten:
- 📱 Responsive Design (funktioniert auf allen Geräten)
- 💾 Lokale Datenspeicherung (localStorage)
- 📊 Live-Visualisierung
- 📤 Export/Import (JSON, CSV)
- 🇩🇪 Deutsche Sprache
- ⚡ Offline-fähig
- 🎯 ICQ-basierte Bewertung

## Technische Details

**ICQ-Anwendung:**
- **Schlaf:** Bewegungs-Kohärenz = Schlafruhe
- **Laufen:** Schritt-Konsistenz = Technik-Qualität
- **Audio:** Frequenz-Stabilität = Klangqualität
- **Herz:** HRV-Kohärenz = Entspannung
- **Maschine:** Vibrations-Muster = Geräte-Gesundheit

**Browser-Support:**
- Chrome/Edge (Desktop + Mobile) ✅
- Safari (iOS + macOS) ✅
- Firefox ✅
