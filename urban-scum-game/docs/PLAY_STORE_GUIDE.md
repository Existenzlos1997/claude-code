## 🖼️ Graphic Assets Requirements

### Hi-res App Icon
- **Size:** 512 x 512 pixels
- **Format:** 32-bit PNG (with alpha)
- **Notes:** No transparency required, but rounded corners are applied automatically

### Feature Graphic
- **Size:** 1024 x 500 pixels
- **Format:** JPG or 24-bit PNG (no alpha)
- **Content suggestions:**
  - Show the game logo prominently
  - Include the main character
  - Use vibrant colors matching the game theme
  - Add tagline: "Run. Jump. Conquer!"

### Screenshots (Minimum 2, Maximum 8)
- **Phone:** 1080 x 1920 pixels (or 1920 x 1080 for landscape)
- **Tablet 7":** 1200 x 1920 pixels
- **Tablet 10":** 1600 x 2560 pixels

**Suggested Screenshots:**
1. Main menu screen with logo
2. Level selection screen
3. Gameplay from Level 1
4. Power-up collection moment
5. Boss enemy encounter
6. Level complete celebration
7. Game over screen with highscore
8. Coins and score display

### Promo Video (Optional but Recommended)
- **Format:** YouTube URL
- **Duration:** 30 seconds to 2 minutes
- **Content:** Show gameplay highlights, power-ups, level variety

|---------|-------------|---------|

| Rewarded | ca-app-pub-XXXXXXXXXXXXXXXX/XXXXXXXXXX | [Your ID] |

## 📊 Monetization Strategy

### Ad Implementation

| Event | Ad Type | Frequency |
|-------|---------|-----------|
| Level Complete | Interstitial | Every 2-3 levels |
| Game Over | Rewarded (Extra Life) | Optional (user-initiated) |
| Main Menu | Banner (optional) | Persistent |

### Revenue Optimization Tips
- Show interstitial ads at natural break points
- Make rewarded ads valuable (extra life, power-ups)
- Don't interrupt gameplay with forced ads
- Respect user experience to maintain retention
