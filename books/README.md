# 📖 Zeitstrahl Reihe - Buchprojekt

Dieses Projekt umfasst zwei parallel verlaufende Buchreihen und ein gemeinsames Finale.

## 📚 Struktur

### Reihe A - Die Mutter (6 Bände)
Die Geschichte einer Heldin, die gegen die dunkle Macht kämpft, ohne zu ahnen, dass ihr größter Feind ihr eigenes Kind ist.

### Reihe B - Das Kind (6 Bände)
Die tragische Geschichte eines Kindes, das im Waisenhaus aufwächst und durch Manipulation zur größten Bedrohung der Welt wird.

### Finale - Die letzte Konfrontation (1 Buch)
Die finale Begegnung zwischen Mutter und Kind, die in einer Tragödie endet.

## 🔄 Lesereihenfolge

Die Reihen können auf verschiedene Arten gelesen werden:
1. **Nur Reihe A** → Finale
2. **Nur Reihe B** → Finale
3. **Beide Reihen parallel** (empfohlen):
   - A1 → B1 → A2 → B2 → A3 → B3 → A4 → B4 → A5 → B5 → A6 → B6 → Finale
4. **Erst A komplett, dann B** → Finale
5. **Erst B komplett, dann A** → Finale

## 🎯 Konzept

Die beiden Reihen erzählen die gleiche Geschichte aus zwei unterschiedlichen Perspektiven:
- **Reihe A**: Die klassische Heldenreise einer Mutter, die das Böse besiegen will
- **Reihe B**: Die Entstehung des Bösen aus der Perspektive des Kindes

Erst im Finale treffen beide Geschichten aufeinander und enthüllen die volle Tragödie.
