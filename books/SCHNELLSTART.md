# Schnellstart - Zeitstrahl Reihe Buchprojekt

Willkommen zum Zeitstrahl Reihe Buchprojekt! Diese Anleitung hilft dir beim Einstieg.

## 📚 Was ist das?

Ein episches Buchprojekt mit zwei parallel verlaufenden Reihen und einem gemeinsamen Finale:
- **Reihe A:** Die Geschichte einer Mutter (6 Bände)
- **Reihe B:** Die Geschichte ihres Kindes (6 Bände)
- **Finale:** Die tragische Konfrontation (1 Buch)

## 🚀 Schnellstart für Autoren

### 1. Überblick verschaffen

Lies zuerst diese Dateien:
```
books/README.md          # Gesamtübersicht
books/ZEITSTRAHL.md      # Zeitliche Einordnung
```

### 2. Wähle eine Reihe zum Schreiben

**Für Reihe A (Mutter):**
```
books/reihe-a-mutter/README.md
books/reihe-a-mutter/band-a1-die-prophezeiung/README.md
```

**Für Reihe B (Kind):**
```
books/reihe-b-kind/README.md
books/reihe-b-kind/band-b1-waisenkind/README.md
```

### 3. Beginne mit dem Schreiben

Jeder Band hat:
- `README.md` - Detaillierte Beschreibung des Bandes
- `kapitel/` - Ordner für die Kapitel (wird noch gefüllt)

**Beispiel:** Für Band A1, Kapitel 2:
```
books/reihe-a-mutter/band-a1-die-prophezeiung/kapitel/02-die-prophezeiung.md
```

## ✍️ Schreibtipps

### Für Reihe A (Mutter):
- Fokus auf Heldenreise und Prophezeiung
- Sie weiß nichts über ihr Kind
- Tragödie durch Unwissenheit
- Traditionelle Fantasy-Erzählung

### Für Reihe B (Kind):
- Fokus auf Entstehung des Bösen
- Das Kind weiß nichts über seine Mutter
- Tragödie durch Umstände
- Dunkle, psychologische Erzählung

### Für das Finale:
- Erst schreiben, wenn beide Reihen weit fortgeschritten sind
- Beide Perspektiven müssen berücksichtigt werden
- Keine Seite ist "gut" oder "böse"
- Das Ende muss tragisch sein

## 🎯 Wichtige Punkte

1. **Zeitliche Konsistenz:** Beide Reihen spielen zur gleichen Zeit
2. **Perspektive:** Jede Reihe sieht die Ereignisse anders
3. **Unabhängigkeit:** Jede Reihe kann alleine gelesen werden
4. **Zusammenhang:** Das Finale vereint beide Geschichten
5. **Tragödie:** Es gibt kein Happy End

## 📖 Empfohlene Schreibreihenfolge

### Parallel (empfohlen):
1. A1 und B1 gleichzeitig entwickeln
2. A2 und B2 gleichzeitig entwickeln
3. Usw. bis A6 und B6
4. Zum Schluss das Finale

**Vorteil:** Zeitliche Konsistenz bleibt gewahrt

### Sequenziell:
1. Erst A1-A6 komplett
2. Dann B1-B6
3. Dann Finale

**Vorteil:** Fokus auf eine Perspektive
