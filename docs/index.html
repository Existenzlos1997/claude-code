⚡ Schnellinstallation

Wähle dein Betriebssystem und führe den Befehl in einem Terminal aus.

Terminal öffnen und folgendes einfügen:

curl -sSL https://raw.githubusercontent.com/Existenzlos1997/claude-code/main/TradingBot/install.sh | bash

PowerShell als Administrator öffnen und folgendes einfügen:

Invoke-WebRequest -Uri "https://raw.githubusercontent.com/Existenzlos1997/claude-code/main/TradingBot/install.bat" -OutFile "$env:TEMP\install.bat"; Start-Process cmd "/c $env:TEMP\install.bat" -Wait

📥 Manuelle Installation (alternativ)

  1. Repository klonen
    git clone https://github.com/Existenzlos1997/claude-code.git && cd claude-code/TradingBot
  2. Abhängigkeiten installieren
    pip install -r requirements.txt
  3. API-Key eintragen
    config.json öffnen → api_key und api_secret von Kraken eintragen.
    nano config.json
  4. Bot starten
    python main.py

📱 Smartphone-App installieren (PWA)

Das Dashboard des Bots ist als Progressive Web App auf jedem Smartphone installierbar – ganz ohne App Store!

  1. Bot auf einem PC/Server starten: python main.py
  2. Im Smartphone-Browser öffnen: http://IP-ADRESSE:5050
  3. Android: Menü (⋮) → "App installieren" oder "Zum Startbildschirm hinzufügen"
  4. iOS (Safari): Teilen-Symbol → "Zum Home-Bildschirm"
