✨ Features
Alles was du für automatisierten Krypto-Handel brauchst
🧠

MQG-Informationsfeldanalyse

Einzigartiger ICQ-Score erkennt Marktphasen durch Interferenzmuster-Analyse auf OHLCV-Daten.

📱

Smartphone-Dashboard

Web-Dashboard als PWA installierbar auf Android & iOS. Live-Updates via WebSocket.

🛡

Intelligentes Risk-Management

Kelly-Criterion, Trailing-Stop, Drawdown-Schutz und automatisches Compound-Reinvestment.

📈

Backtesting

Historische Simulation mit Equity-Kurve bevor echtes Geld eingesetzt wird.

🔒

Sandbox-Modus

Standardmäßig Paper-Trading – kein echtes Geld bis du bereit bist.

🏦

Broker-Support

Kraken (BaFin-reguliert) & Binance direkt integriert.

⚡ Installation
Wähle deine Plattform
🤖

Android (Termux)

Empfohlen

1. Termux via F-Droid installieren  ·  2. Befehl einfügen  ·  3. Fertig!

pkg install curl -y && curl -sSL https://raw.githubusercontent.com/Existenzlos1997/claude-code/main/TradingBot/install_android.sh | bash

Nach dem Start: http://localhost:5050 im Handy-Browser öffnen → "Zum Startbildschirm hinzufügen"

🐧

Linux / macOS

curl -sSL https://raw.githubusercontent.com/Existenzlos1997/claude-code/main/TradingBot/install.sh | bash
🪟

Windows

Invoke-WebRequest -Uri "https://raw.githubusercontent.com/Existenzlos1997/claude-code/main/TradingBot/install.bat" -OutFile "$env:TEMP\install.bat"; Start-Process cmd "/c $env:TEMP\install.bat" -Wait

In PowerShell ausführen (als Administrator)

📲

Dashboard als App installieren

Nach dem Bot-Start: http://localhost:5050 im Browser öffnen.
Chrome/Safari: Menü → "Zum Startbildschirm hinzufügen"
Das Dashboard läuft dann wie eine native App!
