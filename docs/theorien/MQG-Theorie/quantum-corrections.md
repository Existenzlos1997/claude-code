# Quantenkorrekturen in der MQG-Theorie

## 1. Einführung

Quantenkorrekturen modifizieren die klassischen Einstein-Gleichungen auf kleinen Skalen.

## 2. Störungstheoretischer Ansatz

### 2.1 Entwicklung
```
S = S_0 + ℏS_1 + ℏ²S_2 + ...
```

### 2.2 Feynman-Diagramme
- Propagatoren: <φ(x)φ(y)>
- Vertices: Wechselwirkungsterme

## 3. Ein-Schleifen-Korrekturen

### 3.1 Vakuumpolarisation
```
Π_μν(k) = ∫d^4x e^{ikx}<0|T[J_μ(x)J_ν(0)]|0>
```

### 3.2 Selbstenergie
Modifikation der Propagatoren durch Quantenfluktuationen.

## 4. Effektive Wirkung

### 4.1 Definition
```
Γ[φ_cl] = -iln(Z[J])|_{J=Γ'[φ_cl]}
```

### 4.2 1PI-Diagramme
Ein-Teilchen-irreduzible Graphen tragen zur effektiven Wirkung bei.

## 5. Renormierung

### 5.1 UV-Divergenzen
- Logarithmische Divergenzen
- Quadratische Divergenzen
- Quartische Divergenzen (in 4D)

### 5.2 Gegenterm-Methode
```
L_ren = L_0 + L_CT
```

## 6. Anomalien

### 6.1 Chirale Anomalie
Verletzung der klassischen Stromerhaltung auf Quantenebene.

### 6.2 Trace-Anomalie
```
<T^μ_μ> ≠ 0
```
selbst für masselose Felder.

## 7. Casimir-Effekt

### 7.1 Vakuumenergie
```
E_Casimir = -ℏcπ²/(720a³)
```
für zwei parallele Platten mit Abstand a.

### 7.2 Kosmologische Implikationen
Beitrag zur Dunklen Energie?

## 8. Hawking-Strahlung

### 8.1 Temperatur
```
T_H = ℏc³/(8πGMk_B)
```

### 8.2 Entropie
```
S_BH = (k_Bc³/4Gℏ)A
```
Bekenstein-Hawking-Entropie.

## 9. Quantengravitationseffekte

### 9.1 Längenskala
L_Planck = √(Gℏ/c³) ≈ 1.6 × 10^{-35} m

### 9.2 Energieskala
E_Planck = √(ℏc⁵/G) ≈ 1.2 × 10^{19} GeV

## 10. Nicht-perturbative Effekte

### 10.1 Instantonen
Tunnelprozesse zwischen verschiedenen Vakua.

### 10.2 Solitonen
Topologisch stabile Lösungen.
