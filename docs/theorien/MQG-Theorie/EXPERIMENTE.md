# Experimentelle Signaturen der MQG-Theorie

## 1. Hochenergie-Astrophysik

### 1.1 Gammastrahlen-Astronomie

**Beobachtung**: Modifikation der Dispersion von hochenergetischen Photonen

**Methode**:
- Beobachtung von Gamma-Ray Bursts (GRBs) bei sehr hohen Energien
- Messung der Ankunftszeit-Differenz zwischen Photonen verschiedener Energien
- Distanz: kosmologisch (z > 1)

**Erwartete Signatur**:
```
Δt/t ≈ (E/E_Pl) · (D/c)
```

Wobei:
- E = Photonenenergie
- E_Pl = Planck-Energie (~10¹⁹ GeV)
- D = Distanz zur Quelle

**Status**: 
- Bisherige Messungen: Keine Abweichung bis E ~ 100 GeV
- Zukünftige Experimente: Cherenkov Telescope Array (CTA)

### 1.2 Kosmische Strahlung

**Beobachtung**: GZK-Cutoff Modifikation

**Erwartung in MQG**:
- Modifizierte Lorentz-Invarianz bei E > 10²⁰ eV
- Änderung der Pion-Produktionsschwelle
- Mögliche Verschiebung des GZK-Cutoffs

**Experimente**:
- Pierre Auger Observatory
- Telescope Array

## 2. Gravitationswellen-Astronomie

### 2.1 LIGO/Virgo/KAGRA Beobachtungen

**Signatur 1**: Dispersionseffekte

```
v_Gruppe/c = 1 - α·(f/f_Pl)² + ...
```

**Test**: Vergleich der Ankunftszeiten verschiedener Frequenzkomponenten

**Signatur 2**: Modifizierte Wellenformen

- Abweichungen von General Relativity (GR) Vorhersagen in der späten Inspiralphase
- Post-Merger-Signal könnte zusätzliche Peaks zeigen

**Sensitivität**:
- Aktuelle Limits: |α| < 10⁻¹⁵
- Zukünftig (Einstein Telescope): |α| < 10⁻¹⁸

### 2.2 Pulsar-Timing-Arrays

**Methode**:
- Beobachtung von millisecond pulsars über Jahre
- Korrelationsanalyse der Timing-Residuen
- Suche nach stochastischem Gravitationswellen-Hintergrund

**MQG-Signatur**:
- Modifiziertes Spektrum: h_c(f) ∝ f^(-2/3+δ)
- δ ≠ 0 würde auf MQG-Effekte hinweisen

## 3. Schwarze Löcher

### 3.1 Event Horizon Telescope (EHT)

**Beobachtung**: Schatten von supermassiven schwarzen Löchern

**MQG-Vorhersage**:
- Modifizierter Schattenradius: r_shadow = r_GR · (1 + ε)
- ε ~ (ℏc/GM²) für M = 10⁹ M_☉: ε ~ 10⁻⁴⁰ (nicht detektierbar)

**Aber**: Extremere Szenarien könnten messbar sein

### 3.2 Hawking-Strahlung

**Klassische Vorhersage**: T_H = ℏc³/(8πGMk_B)

**MQG-Modifikation**:
```
T_H,MQG = T_H · [1 + β·(M_Pl/M)² + ...]
```

**Problem**: Nur für mikro-schwarze Löcher relevant (falls sie existieren)

**LHC-Suche**:
- Falls extra Dimensionen → niedrigere Planck-Skala
- Suche nach Signaturen von verdampfenden Mini-BHs
- Bisher: Keine Evidenz

## 4. Kosmologische Tests

### 4.1 Cosmic Microwave Background (CMB)

**Planck-Satellit Daten**:

**Test 1**: Primordiale Leistungsspektrum
```
P(k) = P_0(k) · [1 + δP_MQG(k)]
```

**Test 2**: Nicht-Gaussianität
- MQG könnte zusätzliche nicht-Gaussianität erzeugen
- Parameter f_NL

**Aktuelle Grenzen**: f_NL < 10 (sehr restriktiv)

### 4.2 Large Scale Structure

**Beobachtung**: Galaxienverteilung, Weak Lensing

**MQG-Einfluss**:
- Modifikation des Wachstumsfaktors δ(a)
- Änderung der σ₈-Normierung

**Experimente**:
- Dark Energy Survey (DES)
- Euclid
- Vera Rubin Observatory

## 5. Laborexperimente

### 5.1 Atominterferometrie

**Prinzip**: Quanteninterferenz massiver Teilchen

**MQG-Effekt**:
- Modifikation der Phasenverschiebung in Schwerefeld
- φ_MQG ~ (m/M_Pl) · g · T² · L

**Experimente**:
- Atomfontäne-Uhren
- Fallende Ecken-Retroreflektoren
- Satellitenbasierte Tests (ACES, STE-QUEST)

### 5.2 Torsionspendel

**MICROSCOPE-Mission**:
- Test des Äquivalenzprinzips
- Genauigkeit: 10⁻¹⁵

**MQG-Verletzung?**:
- Könnte zu kompositionsabhängigen Effekten führen
- Bisher: Keine Abweichung gefunden

## 8. Herausforderungen

1. **Planck-Skalen-Unterdrückung**: Die meisten Effekte sind extrem klein
2. **Astrophysikalische Unsicherheiten**: Schwer, Systemeffekte zu kontrollieren
3. **Theorie-Ambiguität**: Verschiedene MQG-Modelle, verschiedene Vorhersagen
4. **Hintergrund-Rauschen**: Oft größer als erwartetes Signal
