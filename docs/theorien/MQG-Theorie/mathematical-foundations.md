# Mathematische Grundlagen der MQG-Theorie

## 1. Differentialgeometrische Strukturen

### 1.1 Mannigfaltigkeiten
Die Raumzeit wird als 4-dimensionale pseudo-Riemannsche Mannigfaltigkeit (M, g) modelliert.

### 1.2 Metrischer Tensor
Der metrische Tensor g_μν erfüllt die Signatur (-,+,+,+) und bestimmt die kausale Struktur.

### 1.3 Christoffel-Symbole
```
Γ^λ_μν = (1/2)g^λσ(∂_μ g_νσ + ∂_ν g_μσ - ∂_σ g_μν)
```

## 2. Quantenfeldtheorie auf gekrümmter Raumzeit

### 2.1 Klein-Gordon-Gleichung
```
(□ + m² + ξR)φ = 0
```
mit:
- □: d'Alembert-Operator
- R: Ricci-Skalar
- ξ: Kopplungskonstante

### 2.2 Vakuumzustand
Der Vakuumzustand ist nicht eindeutig definiert und hängt von der Wahl des Beobachters ab.

## 3. Spinor-Strukturen

### 3.1 Dirac-Gleichung
```
(iγ^μD_μ - m)ψ = 0
```

### 3.2 Vielbeine
e^a_μ: Übergang zwischen Raumzeit- und Tangentialraum-Indizes

## 4. Eichtheorien

### 4.1 Yang-Mills-Felder
```
F_μν = ∂_μA_ν - ∂_νA_μ + [A_μ, A_ν]
```

### 4.2 Kovariante Ableitung
```
D_μ = ∂_μ + igA_μ
```

## 5. Symplektische Geometrie

### 5.1 Phasenraum
Der klassische Phasenraum (Γ, ω) mit symplektischer Form ω.

### 5.2 Poisson-Klammern
```
{f, g} = ω^{-1}(df, dg)
```

## 6. Funktionalanalysis

### 6.1 Operator-Algebren
C*-Algebren und von-Neumann-Algebren als mathematischer Rahmen.

### 6.2 Spektraltheorie
Spektrum selbstadjungierter Operatoren repräsentiert Messwerte.

## 7. Topologische Aspekte

### 7.1 Charakteristische Klassen
- Chern-Klassen
- Pontryagin-Klassen
- Euler-Charakteristik

### 7.2 Index-Theoreme
Atiyah-Singer-Index-Theorem verbindet Topologie mit Analysis.

## 8. Renormierungsgruppe

### 8.1 RG-Fluss
```
β(g) = μ(dg/dμ)
```

### 8.2 Fixpunkte
Asymptotische Sicherheit bei UV-Fixpunkt.
