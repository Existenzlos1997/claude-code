## 🎯 Gameplay-Tipps

### Für Anfänger
1. **Langsam starten** - Lerne die Steuerung
2. **Schilde beachten** - Sie schützen deine Gesundheit
3. **Boost sparen** - 2 Sekunden Cooldown
4. **Asteroiden meiden** - Sie verursachen Schaden

### Für Fortgeschrittene
1. **Vorausschießen** - Feinde bewegen sich
2. **Ausweichmanöver** - Nutze 3D-Raum
3. **Entfernung nutzen** - HUD zeigt Distanz
4. **Score maximieren** - Schnelle Kills = mehr Punkte

## 🔧 Troubleshooting

### Spiel lädt nicht?

**Lösung 1:** Browser aktualisieren (Chrome/Safari neueste Version)  
**Lösung 2:** Cache leeren (Einstellungen → Verlauf löschen)  
**Lösung 3:** Andere Browser versuchen

### Schwarzer Bildschirm?

**WebGL-Check:**
1. Besuche: https://get.webgl.org/
2. Sollte grüner Würfel zeigen
3. Falls nicht: Browser/Gerät unterstützt kein WebGL

**Lösung:** Neueres Gerät oder Browser nutzen

### Laggy/Ruckelt?

**Performance-Tipps:**
1. Andere Apps schließen
2. Niedrigere Bildschirmauflösung
3. Browser neu starten
4. Flugmodus aktivieren (nach Laden)

### Touch-Steuerung funktioniert nicht?

**Checks:**
1. Auf oberen Bildschirmbereich tippen (nicht Buttons)
2. Finger auf Bildschirm ziehen (nicht tippen)
3. Mehrere Finger vermeiden
