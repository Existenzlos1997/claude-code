## 🎮 Features

### Gameplay
- **Touch-Steuerung** - Intuitives Drag & Touch Interface
- **6 Fraktionen** - Wähle aus den Originalfraktionen
- **Space Combat** - Zerstöre feindliche Jäger
- **Missionen** - Erreiche Ziele und sammle Punkte
- **Progressive Difficulty** - Steigender Schwierigkeitsgrad

### Technisch
- **Keine Installation** - Direkt im Browser spielen
- **Offline-fähig** - Nach erstem Laden auch offline spielbar
- **localStorage** - Fortschritt wird gespeichert
- **Responsive** - Passt sich jedem Bildschirm an
- **Keine Dependencies** - Single HTML File

## 🕹️ Steuerung

### Flugsteuerung
- **Touch & Drag auf dem Bildschirm** - Schiff bewegen
- Das Schiff folgt deinem Finger

### Buttons
- **🔥 Fire Button (links)** - Schießen
- **⚡ Boost Button (rechts)** - Geschwindigkeitsboost aktivieren

## 🎯 Spielziel

Zerstöre **10 feindliche Jäger** um die Mission zu gewinnen!

## 📊 HUD Elemente

- **💚 Gesundheit** - Deine Lebenspunkte
- **⚡ Schilde** - Schild-Energie (absorbiert Schaden)
- **🎯 Score** - Deine Punkte (100 pro Feind)

## 🌟 Fraktionen

Wähle aus 6 verschiedenen Fraktionen:

1. **🛡️ UEDF** - United Earth Defense Force
2. **💰 FTC** - Free Traders Coalition  
3. **🔬 Explorers Guild** - Wissenschaft & Forschung
4. **☠️ Crimson Syndicate** - Rebellen & Freiheitskämpfer
5. **⚙️ Technocratic Enclave** - Technologie & Innovation
6. **🌟 Colonial Independence** - Kolonisten & Pioniere

Jede Fraktion hat ihre eigene Schiffsfarbe!

## 💾 Speicherung

Das Spiel speichert automatisch:
- Deine Fraktion
- Deinen High Score
- Wann du zuletzt gespielt hast

Alles im Browser localStorage - keine Server, keine Accounts!

## 📖 Installation (Optional)

### Als Web-App speichern (iOS)
1. Öffne die URL in Safari
2. Tippe auf "Teilen" Button
3. Wähle "Zum Home-Bildschirm"
4. Fertig! App-Icon auf deinem Home-Screen

### Als Web-App speichern (Android)
1. Öffne die URL in Chrome
2. Tippe auf Menu (⋮)
3. Wähle "Zum Startbildschirm hinzufügen"
4. Fertig! App-Icon auf deinem Home-Screen

## 💡 Tipps & Tricks

1. **Boost sparsam nutzen** - Hat 2s Cooldown
2. **Schilde regenerieren nicht** - Vermeide Treffer!
3. **Gegner kommen von allen Seiten** - Bleib in Bewegung
4. **Explosionen geben viele Partikel** - Cool anzusehen! 😎
